# Repository design

The repository is organised by technical competency rather than by assignment
number. This makes the work easier to review while preserving the progression
of the course:

- Linux and systems programming;
- device-to-device networking;
- PLC control languages;
- industrial data protocols; and
- modular robotics middleware.

The assignments are not presented as one deployed system. Their relationship
is explained in [`architecture/learning-path.md`](../architecture/learning-path.md).
